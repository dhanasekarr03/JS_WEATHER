# Weather Forecast App

This is my JavaScript project for the Internshala training. I built a weather app that shows current weather and a 5-day forecast for any city. You can also use your device's GPS to get weather for your current location.

I used HTML, Tailwind CSS, and vanilla JavaScript. No frameworks — just plain JS because that's what I'm learning right now.

# Features
- Search weather by typing a city name
- Use your current location (GPS) to get local weather
- See a 5-day forecast with date, temperature, wind speed, and humidity
- Recently searched cities show up in a dropdown (saved using sessionStorage)
- Toggle between °C and °F for today's temperature
- Alert pops up if temperature is above 40°C or below -10°C (extreme weather)
- Background color changes based on weather — blue/dark for rain, warm for sunny, etc.
- Error messages show as popups on screen, not as browser alert() boxes
